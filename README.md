### 👩‍💻 About Me

> **"I engineer high-performance cross-platform mobile and desktop applications with clean architecture and native speed."**

I am a product-focused **Mobile & Desktop Software Engineer** with extensive experience delivering production-grade applications in high-stakes domains (Tax, LegalTech & E-Commerce). My flagship work includes building core user journeys for **Taxmann Store**, high-speed legal search in **Centax Online**, and architecting a lightweight, native **Virtual Book Reader powered by Tauri & Rust**.

- 🎯 **Domain Focus:** Cross-platform mobile development (React Native), high-efficiency native desktop engineering (Tauri / Rust), state management (Redux), and secure offline document rendering.
- ⚡ **Performance Obsessed:** Replacing heavy desktop runtimes with lightweight native architectures (<40MB RAM), sub-second search indexing, and 60 FPS UI transitions.
- 💬 **Ask me about:** React Native, Tauri Desktop Architecture, Rust integration, Redux State Flows, Firebase, and Offline-First Local Storage.
